The Smart Home Lost-Object Finder is an innovative embedded systems project designed to help users easily locate commonly misplaced household objects such as keys, TV remotes, and wallets. It uses an ESP32 microcontroller as the main controlling unit.
The system uses a 4×4 keypad to select the object that needs to be found. A 16×2 LCD display shows the selected object and search status. Three separate LEDs and buzzers are assigned to keys, remotes, and wallets.
When the user selects an object using the keypad, the ESP32 processes the input and activates the corresponding LED and buzzer. This helps the user identify the location of the selected object easily.Applications
Smart homes
Finding misplaced keys
Locating TV remotes
Finding wallets
Everyday household object management

Future Scope

Conclusion
The Smart Home Lost-Object Finder is a useful ESP32-based project that makes finding frequently misplaced household objects easier. By combining a keypad, LCD display, LEDs, and buzzers, the system provides a simple and effective way to identify selected objects and demonstrates the practical applications of embedded systems in smart homes.
